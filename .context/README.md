| File/directory | Purpose |
| --- | --- |

Keep entries compact and reconcile them with live files and git state. Move stable behavior and workflow into `docs/` and leave links here. Never store credentials, private keys, exported profiles, or raw sensitive diagnostics. Keep only necessary nonsecret launch observations once launch happens.
